Accessibility statement

{{ controller }} is committed to making {{ branding.site_name }} accessible, in accordance with Directive (EU) 2016/2102 and the harmonised standard EN 301 549, which refers to the Web Content Accessibility Guidelines (WCAG) 2.1 at level AA.

Compliance status

{{ branding.site_name }} is partially compliant with WCAG 2.1 level AA because of the exceptions listed below.

What we do

  • Every page has a “Skip to main content” link, landmarks, a unique title and a logical heading order.
  • All functions can be used with the keyboard, with a visible focus indicator.
  • Form fields have labels; errors are described in text, listed at the top of the form and linked to the fields.
  • Status changes (saving, run progress, messages) are announced to screen readers.
  • Light and dark themes meet the 4.5:1 text contrast ratio; administrators cannot choose brand colors below it.
  • Animations stop when your system asks for reduced motion; pages reflow to 320 CSS pixels without horizontal scrolling and support 200% zoom.
  • Charts produced by workflows come with a data table and a downloadable SVG.

Content that is not fully accessible

  • Workflow canvas. Moving tasks and drawing links uses drag and drop (WCAG 2.5.7 is not required at level AA in 2.1, but 2.1.1 applies). Keyboard alternatives: add tasks with the palette buttons, select a task with Tab and Enter, move it with the arrow keys, and create or remove data links and dependencies in the Inspector fields (Inputs and Runs after).
  • Text and code editor. Multi-line fields use the Monaco editor. In text fields Tab moves to the next field; in code fields press Ctrl+M (Ctrl+Shift+M on macOS) to make Tab move focus, and Alt+F1 for its accessibility help. Its support for some screen readers is limited; you can import a workflow file prepared in another editor instead.
  • Run graph. The graph is a visual summary; the same statuses are available as text in the task list and log.
  • Third-party sign-in pages (Google, Microsoft or your institution) are outside our control.
